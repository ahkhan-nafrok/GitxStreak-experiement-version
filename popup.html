Track a repo

Use a fine-grained personal access token, scoped to just Contents: Read (plus private-repo access if you want to track private repos), with an expiration set. The token is encrypted before it's stored — see below for how.

How this is protected

The token is encrypted with a key that's generated to be non-extractable — this extension's own code can use it to encrypt and decrypt, but can never read its raw bytes back out. That key lives separately from the encrypted token, so no passphrase or re-entry is needed, ever, even after a browser or PC restart. The token itself never leaves this extension's own popup/background context, and every request goes only to api.github.com.
